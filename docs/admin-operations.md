# 관리자 현황 및 업무 기능표

## 조사 결과

- PHP 8.2+ 서버 렌더링, Vanilla JS, `public/router.php` → `app/bootstrap.php` → `app/routes.php`.
- 관리자 16개 리소스와 대시보드. 목록·등록·수정·상세·미리보기 라우트를 기존 경로로 유지한다.
- 기존 관리자도 사용자 `ds.css`, `app.css`, `app.js`, 미디어·날짜 어댑터를 로드한다. 관리자 전용 DS·레이아웃·JS로 분리한다.
- 데이터는 `DemoRepository`의 PHP 세션에 저장된다. 가상 데이터 기준 시각은 2026-10-21 12:00 KST이다. DB 영구 보관·실제 인증·역할별 권한·외부 알림 발송·실물 배송·실제 포인트 지급은 없다.
- 인증 경계는 `adminDemo` 세션, CSRF, 내부 redirect 검증, 엔티티·필드 허용 목록이다. 기존 경계를 유지하며 새 서버 액션에도 적용한다. 가상 관리자 역할을 실제 권한 체계로 표시하지 않는다.
- 회원 연락처는 마스킹한다. 개인 매매일지 테이블을 관리자 검색·상세·내보내기에 제공하지 않는다.
- 기존 목록은 검색·필터·날짜순·8개 페이지가 있으나 선택·벌크 처리·조회 상태 복원·페이지 크기 변경은 없다.
- 기존 저장·선정·리뷰 검수·답변·신고 기록은 세션에 반영된다. 회원 상태 변경 사유, 상세 연속 검토, 벌크 결과, 버전 충돌 검사를 보완한다.

## 디자인 기준

UI/UX Pro Max의 Data-Dense Dashboard 결과를 적용한다. 마케팅용 Enterprise Gateway 패턴은 업무 화면에 부적합하므로 적용하지 않는다. 사용자 지정 블루 #2563EB, 기존 한국어 Pretendard, 224px 사이드바, 중성 회색 캔버스, 13px 업무 텍스트, 32px 컨트롤, 40~48px 행, 8px 단위 간격. DS 원본을 복사한 관리자 파일의 원래 토큰 정의를 변경한다. 사용자 CSS/JS는 관리자에서 로드하지 않는다.

## 미연동 범위

실제 관리자 인증·역할 권한·DB·외부 발송·실물 배송·수동 포인트 정책은 기존 프로젝트에 없다. 이 기능들은 완료로 표시하거나 빈 메뉴로 추가하지 않는다. CSV는 검색 조건과 마스킹된 목록 컬럼만 내보낸다. 파일 업로드는 로컬 PHP 저장이며 운영 배포 시 공유 저장소·백업·접근정책 검토가 필요하다.
