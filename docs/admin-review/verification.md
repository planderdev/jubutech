# 관리자 개편 구현·검수 보고

검수일: 2026-10-22 (Asia/Seoul). 가상 세션 데이터만 사용했다. 실제 회원·응모·포인트 데이터 변경 및 외부 발송은 수행하지 않았다.

## 구현 범위

기존 PHP 라우팅과 세션 저장 구조를 유지하면서 대시보드와 16개 관리자 메뉴의 목록·연결된 상세·등록·수정 화면을 개편했다. 메뉴별 컬럼·필드·상태 전환·권한·연동 현황은 [업무 기능표](../admin-operations.md)에 정리했다.

벌크는 **현재 페이지의 최대 100건**만 대상으로 한다. 전체 검색 결과 선택은 지원하지 않는다고 화면에 표시한다. 확인 화면에서 대상 수·ID·작업·사유·영향을 확인하고 서버에서 인증·CSRF·작업 허용 목록·항목별 최신 버전·상태를 검증한다. 처리 후 성공·제외·실패를 구분하고 실패 사유와 현재 페이지 실패 항목 재선택을 제공한다. 순서 저장은 전체 대상 검증 이후 반영한다.

## 상세 화면의 차이

- 콘텐츠·공지: 본문과 노출 설정, 저장된 사용자 화면 미리보기. 콘텐츠 소제목은 `##`로 편집한다.
- 체험단: 모집·선정·리뷰·노출 일정, 미션·질문, 정원·선정 수, 관련 목록 이동.
- 응모: 신청 사유·추가 답변과 선정 판단 정보를 나란히 표시한다.
- 리뷰: 제출 원문과 캠페인 미션을 나란히 표시하고 검수 결과·사용자 전달 사유를 구분한다.
- 신고: 신고 사유·대상 원문·동일 대상 신고와 조치 범위를 표시한다.
- 문의: 회원 원문과 답변 편집을 나란히 표시한다.
- 회원: 마스킹된 운영 정보, 공개 활동·포인트·관련 업무 이동과 상태 변경 사유를 표시한다.
- 포인트·교환: 확정 원장과 교환 단계·연결 원장·반환 내역을 표시한다.
- 배너: 시각 편집과 390px 기준 미리보기, 이미지 검증과 파일 업로드를 제공한다.

## 미연동·미확인 사항

- **운영 배포·DB 영구 보관·실제 관리자 인증·역할별 권한·외부 문자/메일·쿠폰/배송·실제 포인트 지급**은 기존 프로젝트에 없으며 이번 작업으로 연결되지 않았다. 현재 변경은 PHP 세션의 데모 데이터에 저장된다. 데모 역할을 실제 운영 권한으로 표시하지 않는다.
- 여러 실제 관리자 계정과 DB를 통한 동시 접근은 검수할 수 없다. 동일 가상 세션의 오래된 버전·중복 요청 검증을 테스트했다. 운영 전 DB 트랜잭션·원장 유일성 제약과 역할별 정책을 연결해야 한다.
- 기존에 차감 원장이 연결되지 않은 교환 신청은 자동 반환을 거절한다. 실제 발급·배송·반려 정책을 임의로 만들지 않았다.
- 수동 포인트 지급·차감, 대량 지급, 외부 발송, 관리자 영구 삭제 정책, 실제 회원 개인정보 원문 접근은 사용 가능한 기능으로 추가하지 않았다.
- 리뷰·문의의 영구 첨부 모델은 기존 데이터에 없다. 존재하지 않는 첨부를 만들거나 전송 완료로 표시하지 않았다.
- 파일 업로드는 로컬 `public/assets/images/uploads/`에 PNG·WebP만 저장한다. 파일명 무작위화, 이미지 서명·크기·픽셀 제한을 검사한다. 연결 해제는 참조만 해제하며 다른 항목의 파일을 삭제하지 않는다. 운영 환경에서는 공유 저장소·백업·용량·보존 정책 연결이 필요하다.
- 저장 유효성 실패·버전 충돌·재시도는 검수했다. 실제 DB 장애·저장 장치 장애·외부 연동 실패·수동 화면낭독기 검사는 실행하지 않았다. 조회 예외는 재조회 가능한 오류 화면으로 구분한다.
