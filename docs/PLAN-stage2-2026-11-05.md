## 0. 원칙 (1단계와 같음)

- 팀장 PHP(`app/`·`public/`·`tests/`·`docs/admin-operations.md`)는 사양으로만 읽고 고치지 않는다.
- 미정 숫자는 전부 `packages/shared/src/rules.ts` 설정 키. 화면은 PHP 사양 + `baseui` 토큰만.
- Supabase(W8)는 프로젝트 ref·카카오 키가 올 때까지 보류. 목 데이터(`DEMO_*`·zustand)로 만들고, 교체 지점은 코드 주석과 `supabase/migrations/0003_stage2.sql` 초안으로 표시한다.
- 단위마다 커밋(메시지에 "2단계 Wn … (앱 작업분, 팀장 PHP 데모 미변경)"), `npm run typecheck`·`npm run tokens:check` 통과, 화면 단위는 expo web 모바일 뷰포트 캡처를 `docs/screenshots/stage2/` 에 둔다.

## 1. 순서를 정한 근거

사용자가 눈으로 보는 화면이 먼저다. 자리만 있는 탭을 채우고(W1~W3), 그 위에 생활력(W4)과 운영 도구(W5)를 얹는다. 신고 흐름은 커뮤니티가, 상호 평가는 광고주 화면이, 설정 화면은 앞 단위가 늘린 설정 키가 있어야 의미가 있다. 어댑터·푸시 자리와 3단계 묶음은 뒤에 둔다.
